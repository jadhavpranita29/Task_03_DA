# Walmart sales Analysis

This task uses SQL to analyze a retail sales dataset containing weekly sales, temperature, fuel price, CPI, unemployment rate, and holiday flags.
The goal is to understand sales patterns, identify best-performing stores, compare holiday vs non-holiday performance, and practice essential SQL operations.

# Purpose of the Project

To learn and apply real-world SQL operations such as SELECT, WHERE, GROUP BY, ORDER BY, and JOIN.

To explore how external factors like holidays and temperature impact sales.

To build strong SQL foundations for Data Analyst roles.

| Column Name  | Description                       |
| ------------ | --------------------------------- |
| Store        | Store ID                          |
| Date         | Week date                         |
| Weekly_Sales | Total sales for that week         |
| Holiday_Flag | 1 = Holiday week, 0 = Normal week |
| Temperature  | Temperature on that week          |
| Fuel_Price   | Fuel price in the region          |
| CPI          | Consumer Price Index              |
| Unemployment | Unemployment rate                 |

# Tool Used
SQL Server

| Function    | Meaning           |
| ----------- | ----------------- |
| **SUM()**   | Total value       |
| **AVG()**   | Average value     |
| **COUNT()** | Number of records |
| **MAX()**   | Highest value     |
| **MIN()**   | Lowest value      |

# Key Insights

Identified top-performing stores based on yearly and weekly sales.

Found that holiday weeks show higher sales compared to normal weeks.

Discovered how external factors like temperature and fuel price influence sales trends.

Observed month-wise sales patterns to understand seasonality.
